uni·ui

面向产品的组件系统

为产品而生的
克制与毛玻璃。

uni-ui 不是后台管理工具箱。它是一套有自身品牌声音、紧凑利落、原生支持暗色与多品牌换肤的组件系统—— 视觉由 token 驱动，DOM 结构跨框架统一。

设计定调（Design Direction）

受众

面向 C 端 / B 端产品界面，非数据密集后台。

调性

苹果 macOS 大气简约 + 毛玻璃半透明 + 紧凑利落。

展示字 / 正文

Cabinet Grotesk / Satoshi，等宽 JetBrains Mono 用于 token。

记忆点

毛玻璃材质 + 电光靛品牌色，换肤只动一个变量。

逐组件独立玻璃控制 — 透明度 / 模糊各自可调，互不干扰

每个玻璃组件都有独立旋钮（--ui-{comp}-glass-opacity / --ui-{comp}-glass-blur），未设时回退全局默认。透明度与模糊是两条独立通道；改任一组件不影响其它。

独立旋钮（拖动只改对应组件）

旋钮写在 :root 即改该类型全部实例；写在单个元素 style 上只改那一个实例。两条通道（透明度 / 模糊）互不影响。

Components

核心组件（紧凑利落 macOS 风）

Button · 变体 × 尺寸 × 状态 × 外部图标

本预览默认接入 lucide 图标体系：icon 插槽内写 <i data-lucide="plus"></i>，由 createIcons() 替换为真实 SVG。组件不内置图标，尺寸由 --ui-icon-size 控制，颜色继承文字，可随时换 heroicons 等任意库。

尺寸矩阵 — 4 档（大 / 中 / 微 / 小），统一 ui-size-* 驱动

所有控件只读“当前档”变量（--ui-control-h / --ui-fs-control / --ui-pad-x / --ui-icon-size），尺寸类（.ui-size-xs / sm / lg）重定义它们，组件不感知 size。md 为默认，故仅三档类。
